# MyLibrary - GCS

Sistema fullstack de biblioteca pessoal desenvolvido para a avaliação N2 integrada de Gerência de Configuração de Software.

## 📁 Estrutura do Repositório
- `backend/mylibrary-backend/` - API Spring Boot (Java 21 + Maven)
- `frontend/mylibrary-frontend/` - Frontend SPA (Angular 17 + Node 20)

## 🚀 Como Executar

### ☕ Backend
`bash` 
`cd backend/mylibrary-backend` 
`mvn spring-boot:run`

## 🅰️ Frontend
`cd frontend/mylibrary-frontend` 
`npm ci` 
`npm run start`
